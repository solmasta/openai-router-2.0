# OpenAI Router 2.0 - Initial Release

## Overview

OpenAI Router 2.0 is an AI routing control center for managing providers, executing requests, and monitoring AI services.

## Included

- AI provider routing system
- Local provider support
- Mock provider support
- Streaming execution API
- React dashboard
- Provider monitoring
- Metrics and control panels
- Termux-compatible build workflow
